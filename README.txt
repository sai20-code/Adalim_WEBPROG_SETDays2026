1. WEBSITE THEME & CONCEPT
----------------------------------------------------------------------
Theme Title: "SET Days 2026: Designing the Future"
Tagline    : "Where Curious Minds Meet Next-Gen Innovation"

Concept Overview:
This website serves as an informational event portal for the proposed 
SET Days (School of Engineering and Technology Days) 2026 celebration, 
scheduled for December 2–4, 2026. The concept centers on bridging 
classroom theory with hands-on student innovation through collaborative 
challenges (such as the Campus Smart-Solutions Hackathon and Structural 
Bridge-Building Contest), technical seminars, and interactive showcases.

Design & Layout Concept:
- Built primarily with semantic HTML5 elements for clear document 
  structure and internal anchor navigation.
- Styled using an external stylesheet (style.css) featuring a blended 
  light-to-royal blue color palette to evoke a clean, modern tech and 
  engineering aesthetic.
- Includes an interactive venue map divided into three clickable zones 
  (Campus, Court, and Game Park) using HTML <map> and <area> tags.

Disclaimer:
All event schedules, guest speakers, organizations, and venue layouts 
presented on this website are fictional concepts created strictly for 
academic coursework.
